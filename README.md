# Pruebas Técnicas – PADLOCK S.A.S.

Este repositorio agrupa las soluciones a las pruebas técnicas solicitadas en el proceso de selección para Desarrollador Frontend en PADLOCK S.A.S.

## 📂 Estructura del Repositorio

- **AhorcadoPruebaTecnica/**  
  Contiene la solución de la Prueba 1: **Juego del Ahorcado**  
  _(ver `AhorcadoPruebaTecnica/README.md` para detalles de instalación y uso)_

- **calculatorNode/**  
  Contiene la solución de la Prueba 2: **Calculadora**  
  _(ver `calculatorNode/README.md` para detalles de instalación y uso)_

## ⚙️ Instrucciones Generales

Cada subcarpeta incluye su propio `README.md` con:

1. Tecnologías utilizadas  
2. Pasos de instalación  
3. Ejecución en desarrollo  
4. Descripción de la funcionalidad y cómo usar la aplicación  

La explicacion para ejecutar cada una de las carpetas esta en su respectivo README.md
