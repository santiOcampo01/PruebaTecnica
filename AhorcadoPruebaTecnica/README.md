
## Prueba tecnica - Juego del Ahorcado

Este proyecto recrea el juego del ahorcado y es parte de una prueba tecnica.

---

## Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone https://github.com/santiOcampo01/PruebaTecnica.git
cd PruebaTecnica/AhorcadoPruebaTecnica
```

### 2. Instalar dependencias

```bash
npm install
```

### 2. Iniciar el servidor

```bash
npm run dev
```
este se ejecuta por defecto en http://localhost:4321/


## Cómo Jugar
- Abre tu navegador en http://localhost:4321.

- Aparecerá la interfaz con un canvas para el dibujo y   los huecos de la palabra.

- Escribe una letra en el campo de texto y dar enter o click en probar.

- Las letras correctas se muestran en la posicion, las incorrectas no se mostraran pero aumentaran los errores con un limite de 6.

- Las letras repetidas no penalizan.

- Se puede hacer click en reinicar en cualquier momento.
